⌨ Básico & Arquivo

💾 Salvar & Sair

Ctrl+sSalvar arquivo
:wSalvar
:qFechar janela
:wq / :xSalvar e fechar
:q!Fechar sem salvar
:qa!Fechar tudo sem salvar

📑 Abas (Tabs)

🗂 Gerenciar Abas

Ctrl+tNova aba
Ctrl+qFechar aba atual
TabPróxima aba
Shift+TabAba anterior
:tabnew arquivoAbrir arquivo em nova aba
:tabmove {n}Mover aba para posição n
:tabsListar todas as abas
Dica: use :tabnew e depois ,ff (Telescope) para abrir um arquivo na nova aba.

⚡ Fluxo com Abas

:tabe %Abrir arquivo atual em nova aba
gt / gTPróxima / anterior (alternativo)
2gtIr para aba número 2
:tabonlyFechar todas exceto a atual
Workflow sugerido: abra cada contexto em uma aba (Ctrl+t) e use Tab / Shift+Tab para navegar.

⬜ Splits (Divisão de Janela)

↕ Criar Splits

:sp / :splitDividir horizontalmente
:vsp / :vsplitDividir verticalmente
:sp arquivoAbrir arquivo em split horizontal
:vsp arquivoAbrir arquivo em split vertical

🖱 Navegar entre Splits

Ctrl+w h/j/k/lMover entre painéis
Ctrl+w wPróximo painel (ciclar)
Ctrl+w =Equalizar tamanhos
Ctrl+w |Maximizar largura
Ctrl+w _Maximizar altura
:closeFechar painel atual
:onlyFechar todos exceto o atual

🔴 Breakpoints & UI DAP

💻 Terminal (Floaterm)

⬛ Terminal Flutuante

Ctrl+jToggle terminal flutuante (abre/fecha)

Use Ctrl+j novamente para esconder sem fechar.
Para sair do modo insert no terminal: Ctrl+\ Ctrl+n

📝 Markdown Preview

👁 Preview no Browser

,mpToggle Markdown Preview no browser
Funciona apenas em arquivos .md. O treesitter para markdown está desativado por um bug conhecido no Neovim 0.12+ com fenced code blocks.
